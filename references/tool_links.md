# Essential Bioinformatics Web Portals & Tools

A curated directory of production web servers and documentation portals used throughout the practicals and theory lectures.

---

## 1. Major Resource Hubs

| Hub | URL | Description |
|---|---|---|
| **NCBI** | https://www.ncbi.nlm.nih.gov/ | National Center for Biotechnology Information (GenBank, PubMed, Gene, BLAST) |
| **EMBL-EBI** | https://www.ebi.ac.uk/ | European Bioinformatics Institute (ENA, UniProt, FASTA, Clustal Omega) |
| **Expasy / SIB** | https://www.expasy.org/ | Swiss Institute of Bioinformatics resource portal (ProtParam, ProtScale) |
| **RCSB PDB** | https://www.rcsb.org/ | Protein Data Bank (wwPDB member for 3D atomic structures) |
| **DDBJ** | https://www.ddbj.nig.ac.jp/ | DNA Data Bank of Japan (INSDC partner) |
