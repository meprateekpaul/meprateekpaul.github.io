Reusable Toolkit

The chemlib Python Library

A modular, production-tested package installed via pip install -e . that powers the notebook workflows.

Standardize & Curate

Salt stripping, largest fragment extraction, charge neutralization, canonical tautomerization, and median-aggregated bioactivity filtering.

chemlib.standardize.curate_bioactivity_dataframe()

Molecular Graphs

Adjacency matrices, topological distances, Wiener index, Zagreb M1/M2, Randić index, MWC walk counts, and NetworkX VF2 subgraph matching.

chemlib.graphs.wiener_index(), check_subgraph_isomorphism_vf2()

Modern Fingerprints

Unified modern rdFingerprintGenerator interface for ECFP4/6, MACCS, Daylight, plus 15 vectorized similarity coefficients.

chemlib.fingerprints.compute_similarity_coefficients()

Validation & Metrics

Bemis-Murcko scaffold splitting to prevent leakage, LOO q2, external R2_pred, Matthews Correlation Coefficient (MCC), EF1%, and BEDROC.

chemlib.metrics.scaffold_split(), enrichment_factor()

Pharmacophores

ChemicalFeatures extraction (donors, acceptors, aromatics, cations), 2D Pharm2D signature fingerprints, and 3-point distance matcher.

chemlib.pharm.match_3point_pharmacophore_distances()

AutoDock Vina & Meeko

Automated receptor/ligand PDBQT preparation, box centering, Vina Python API runner, pose extraction, and heavy-atom RMSD.

chemlib.docking.run_vina_docking(), compute_heavy_atom_rmsd()
