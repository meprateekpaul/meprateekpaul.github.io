Pedagogical Principles & Architectural Standards

Every curriculum hosted on this platform adheres to four strict institutional engineering rules:

Executable & Reproducible (No Pseudo-code)

Every notebook has a 1-click Google Colab badge, a fixed random seed (SEED=42), and dual execution modes (FULL_RUN=False for sub-minute CPU smoke runs).

Lecture-Aligned & Rigorously Corrected

Grounded directly in formal university lecture decks with explicit slide errata guides, modernizing deprecated APIs (e.g., modern rdFingerprintGenerator).

Curated Real-World Scientific Datasets

Data registries curated from ChEMBL, PubChem, DrugBank, PDB, and clinical registries. Automated python fetchers guarantee deterministic offline dataset rebuilding.

Reusable Software Frameworks

Modular, pip-installable python packages (chemlib) accompanied by automated pytest suites running in continuous integration (CI) workflows.
